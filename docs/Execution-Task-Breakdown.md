# 《李聪传》AI短剧执行任务拆解

## 目标
在不推翻现有素材的前提下，把当前工作区升级为一条可执行的 AI 短剧生产线，并优先交付 3 条样片。

## 总体阶段

### 阶段 0：资产清点（已完成）
- 已识别输入资产：章节正文、AI 漫剧分镜脚本、镜头 JSON、视频提示词、出版资料、音乐文案
- 已形成策划文档：
  - `Product-Spec.md`
  - `AI-ShortDrama-Technical-Route.md`
  - `GitHub-Tooling-Selection.md`
  - `Execution-Task-Breakdown.md`

### 阶段 1：内容重构（优先）
#### Task 1.1 章节拆集
- 将 9 章内容重构为适合短平台传播的集数设计
- 输出：`episodes.json` 或 `ShortDrama-Episodes.md`

#### Task 1.2 样片脚本
- 先挑 3 条样片：童年篇、少年篇、遇见她篇
- 每条输出：
  - 开头钩子
  - 情绪高潮
  - 结尾悬念
  - 8-12 镜头清单

#### Task 1.3 内容矩阵
- 每条样片衍生：
  - 60-90 秒剧情版
  - 15 秒爆点版
  - 人物版/金句版

### 阶段 2：角色与风格基线
#### Task 2.1 角色卡
- 生成年龄分层的李聪角色卡：幼年 / 童年 / 少年 / 青年 / 成年
- 生成主要配角角色卡：爷爷、奶奶、母亲、继父、张珂
- 输出：`Character-Bible.md`

#### Task 2.2 风格基线
- 固定：画风、色调、镜头语言、时代感、服化道关键词
- 输出：`Visual-Style-Bible.md`

### 阶段 3：生成工作流落地
#### Task 3.1 关键帧工作流
- 用 StoryDiffusion / ComfyUI 产出关键帧
- 输出：角色一致的镜头关键帧目录结构

#### Task 3.2 图生视频工作流
- 用 FramePack / AnimateDiff 跑通 3-8 秒镜头
- 只优先做关键镜头，普通镜头保持静图 + 运动

#### Task 3.3 配音与字幕
- 用 GPT-SoVITS 完成旁白样音与角色样音
- 用 WhisperX 生成字幕时间轴

### 阶段 4：模板化渲染
#### Task 4.1 Remotion 模板
- 设计 9:16 主版模板
- 包含字幕区、安全边距、封面、片尾 CTA

#### Task 4.2 多版本导出
- 输出：
  - 主版（60-90 秒）
  - 爆点版（15 秒）
  - 预告版（30 秒）

### 阶段 5：发布准备
#### Task 5.1 平台包
- 每条视频自动导出：
  - 视频文件
  - 封面图
  - 标题 3 版
  - 简介 2 版
  - 标签清单
  - 发布注意事项

#### Task 5.2 API 与人工分发
- 抖音：预留官方 API 对接能力
- 视频号 / 小红书 / B站：先人工发布

## 样片优先队列

### 样片 A：童年篇
- 来源：第一章《西山脚下》 + 第二章《两个家》
- 卖点：怀旧、亲情、家乡、分离感
- 目标：建立人物初印象与情绪基调

### 样片 B：少年篇
- 来源：第三章《少年心事》 + 第四章《转学记》
- 卖点：成长烦恼、身份认同、少年冲突
- 目标：拉高剧情张力

### 样片 C：遇见她篇
- 来源：第八章《遇见她》
- 卖点：爱情线、人物命运转折、适合传播
- 目标：验证更强情绪表达与评论互动潜力

## 验收标准

### 内容验收
- 能明确看出主角、时代、地点、情绪线
- 开头 3 秒有钩子
- 结尾有悬念或情绪回味

### 画面验收
- 同角色跨镜头可识别
- 风格统一，不出现明显模型漂移
- 普通镜头不强行追求复杂动作，重点镜头质量优先

### 音频验收
- 中文旁白自然
- 字幕时间轴准确
- 关键对白镜头口型可接受

### 发布验收
- 能输出抖音 / 视频号 / 小红书 / B站通用发布包
- 标题、简介、封面可直接进入人工终审与上传
