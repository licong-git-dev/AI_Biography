# 《李聪传》样片 Remotion / FFmpeg 合成方案

> 目的：定义 Sample A / B / C 的时间线层级、字幕、转场、导出逻辑，为后续实现 Remotion 模板或 FFmpeg 合成脚本做准备。

---

## 一、统一合成规格

### Composition
- width: `1080`
- height: `1920`
- fps: `24`
- duration: 按样片实际时长动态计算

### 输出版本
- 主版：`sample-{id}-main-v1.mp4`
- 爆点版：`sample-{id}-hook-15s-v1.mp4`
- 预告版：`sample-{id}-trailer-30s-v1.mp4`
- 无字幕版：`sample-{id}-main-no-subtitles-v1.mp4`
- 烧录字幕版：`sample-{id}-main-burned-subtitles-v1.mp4`

---

## 二、时间线层级

从底到顶：

1. Background / Fill Layer
   - 用于模糊填充或主视觉底图

2. Visual Layer
   - 关键帧或视频镜头
   - 静图镜头使用 Ken Burns 动效
   - 动态镜头直接播放 approved clip

3. Atmosphere Layer
   - 可选：暗角、胶片颗粒、轻微光晕

4. Subtitle Layer
   - 主字幕
   - 金句黑场字幕

5. Title / CTA Layer
   - 封面标题
   - 片尾关注提示

6. Audio Layer
   - 主旁白
   - 对白
   - 环境音
   - BGM

---

## 三、统一视觉处理

### 静图镜头
使用轻微 Ken Burns：
- scale: `1.0 -> 1.06`
- translateX / translateY：小幅移动
- duration：跟随镜头时长

### 视频镜头
- 保持原始运动
- 只做必要裁切与安全区域适配
- 禁止再叠加强烈运动，避免眩晕

### 胶片层
- 轻微 grain
- 暖色 LUT 或统一色彩调整
- 不做强烈滤镜

---

## 四、字幕规范

### 普通字幕
- 位置：画面下方安全区
- 字体：黑体/思源黑体类
- 字色：白色
- 描边：黑色 2-4px 或半透明底条
- 单行优先，最多两行

### 金句字幕
- 位置：居中或偏下
- 黑场/暗场显示
- 字号大于普通字幕
- 保留 0.5s 入场和 0.5s 出场
