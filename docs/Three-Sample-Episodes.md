## 样片 1：童年篇《西山的灯一直亮着》

### 1. 定位
- 来源章节：第一章《西山脚下》 + 第二章《两个家》
- 内容类型：剧情版主样片
- 推荐时长：75-90 秒
- 情绪目标：温暖、怀旧、轻微心酸
- 核心卖点：爷爷奶奶、家乡、西山、两个家之间的来回

### 2. 开头钩子（前 3 秒）
**文案候选：**
1. 三岁那年，我第一次知道，家也会分成两个。
2. 爸妈离婚那天，我还以为那是一件值得炫耀的事。
3. 所有人都问我家在哪，我却有两个答案。

### 3. 情绪高潮
- 父亲背影离开
- 奶奶哄睡与夜晚灯光
- 公交车上看着窗外、手里攥着奶奶给的花生

### 4. 结尾悬念
**文案候选：**
- 我后来才明白，一个孩子最先学会的，往往不是长大，而是忍住想哭。
- 那时候我还不知道，两个家之间来回的人生，才刚刚开始。

## 样片 2：少年篇《那个不说话的男孩》

### 1. 定位
- 来源章节：第三章《少年心事》 + 第四章《转学记》
- 内容类型：成长冲突样片
- 推荐时长：60-75 秒
- 情绪目标：压抑、倔强、刺痛感
- 核心卖点：少年的自尊、转学、沉默、对抗世界

### 2. 开头钩子（前 3 秒）
**文案候选：**
1. 小时候我不爱说话，因为有些难过，说了也没人懂。
2. 那时候所有人都觉得我叛逆，只有我知道自己只是太想赢。
3. 你见过那种看起来很硬，其实一碰就碎的男孩吗？

### 3. 情绪高潮
- 转学进入陌生教室
- 夜里独自躺在床上盯着天花板
- 在学校/家庭压力里忍住情绪

### 4. 结尾悬念
- 后来我才知道，少年时最难的不是吃苦，而是不知道该向谁开口。
- 我以为自己是在对抗别人，其实是在对抗命运给我的那口气。

3. 他们都说我叛逆，可我只是太想证明自己

**版本 A：**
这是《李聪传》的少年篇。很多男孩在成长里都学会了一件事：难过不能说，输也不能认。

## 样片 3：情感篇《遇见她以后》

### 1. 定位
- 来源章节：第八章《遇见她》
- 内容类型：爱情线传播样片
- 推荐时长：60-75 秒
- 情绪目标：温柔、心动、命运转折
- 核心卖点：相遇、被理解、人生开始变亮

### 2. 开头钩子（前 3 秒）
**文案候选：**
1. 有些人出现以后，你才知道自己原来也值得被爱。
2. 我用了很多年学会坚强，却在遇见她以后，重新学会温柔。
3. 她不是来拯救我的，她只是让我第一次想把日子过好。

### 3. 情绪高潮
- 第一次对视
- 日常并肩而行的小动作
- 主角第一次卸下防备的笑

### 4. 结尾悬念
- 后来我才知道，人这一生最幸运的事，不是赢，而是被一个人真正看见。
- 原来命运不是一直在拿走，它也会把一个人轻轻送到你面前。

## 三条样片统一发布包规范

### 每条必须导出
- 主版视频：1 条（60-90 秒）
- 爆点切片：1 条（15 秒）
- 预告版：1 条（30 秒）
- 封面图：3 张备选
- 标题：3 条
- 简介：2 条
- 标签：6-8 个

### 审核清单
- 人物是否稳定可识别
- 开头 3 秒是否有钩子
- 字幕是否手机端易读
- BGM 是否压过旁白
- 封面是否一眼能看懂情绪冲突

### 推荐执行顺序
1. 先做样片 1，建立 IP 气质
2. 再做样片 3，验证传播性
3. 最后做样片 2，验证剧情厚度
