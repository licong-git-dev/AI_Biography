# Sample A 验收清单

> 目的：为 Sample A 提供逐环节验收标准。任何环节不过关，不要直接进入下一步。

---

## 1. 关键帧验收

### A-01 西山清晨
- [ ] 一眼能看出是中国现实语境，不是泛风景图
- [ ] 有山、晨雾、日出、村庄四个核心元素
- [ ] 色调偏暖，不发冷灰
- [ ] 有“来处”和“根”的气质

### A-02 老屋外景
- [ ] 老屋真实、旧、有生活痕迹
- [ ] 不是民宿风，不精致过头
- [ ] 有向日葵/晾衣绳等家庭记忆锚点

### A-04 奶奶哄睡
- [ ] 奶奶形象可信，不是 AI 假脸
- [ ] 灯影柔和，不刺眼
- [ ] 有明确安静、哄睡、家感

### A-05 父母背对背
- [ ] 冲突一眼可见
- [ ] 构图有压迫感
- [ ] 不狗血，不夸张咆哮

### A-06 父亲离开
- [ ] 父亲背影和孩子伸手关系明确
- [ ] 情绪到位
- [ ] 具备升成视频镜头的潜力

### A-08 奶奶送别
- [ ] 奶奶和孩子情绪真实
- [ ] 车窗倒影具备记忆点
- [ ] 可直接做封面候选

---

## 2. 图生视频验收

### 动态镜头通用要求
- [ ] 人脸没有明显漂移
- [ ] 手部没有严重变形
- [ ] 运动节奏平稳，不抽搐
- [ ] 没有过度夸张镜头运动
- [ ] 画风和关键帧保持一致

### 重点镜头
- [ ] A-01 有缓慢航拍感
- [ ] A-05 沉默张力成立
- [ ] A-06 离开动作自然
- [ ] A-08 送别情绪成立

---

## 3. 音频验收

### 旁白
- [ ] 声线自然，不像广告配音
- [ ] 语速稳定
- [ ] 没有明显 AI 断句错误
- [ ] 关键词重音合理

### 对白
- [ ] 奶奶一句台词自然
- [ ] 不油腻，不夸张

### 环境音 / BGM
- [ ] 鸟鸣、早餐摊、公交环境音不抢戏
- [ ] BGM 没有压住旁白
- [ ] 情绪推进合理，不乱煽情

---

## 4. 字幕验收

- [ ] 字幕内容与旁白一致
- [ ] 人名、地名无错字
- [ ] 单行长度适合手机端阅读
- [ ] 停顿点和字幕切分合理
- [ ] 金句黑场字幕醒目但不土

---

## 5. 合成验收

### 主版
- [ ] 开头 3 秒钩子成立
- [ ] 75-90 秒节奏不拖
- [ ] 画面、旁白、字幕是一个情绪
- [ ] 最后一句金句能收住

### 爆点版 15 秒
- [ ] 有明确冲突点
- [ ] 适合刷短视频时快速理解

### 预告版 30 秒
- [ ] 有世界观建立 + 冲突 + 收束

---

## 6. 封面验收

### 主封面
- [ ] 一眼能看出“童年 / 家庭 / 离别”
- [ ] 文案不超过一眼阅读负担
- [ ] 人物面部清晰

### 备选封面
- [ ] 奶奶送别版更偏情绪
- [ ] 西山晨雾版更偏系列气质

---

## 7. 发布包验收

- [ ] 标题至少 3 条
- [ ] 简介至少 2 条
- [ ] 标签 6-8 个
- [ ] 置顶评论至少 2 条
- [ ] 文件命名统一
- [ ] 可直接交给人工终审发布

---

## 8. 最终通过标准

只有当下面全部满足，Sample A 才算真正完成：
- [ ] 主版通过
- [ ] 爆点版通过
- [ ] 预告版通过
- [ ] 封面通过
- [ ] 发布文案包通过
- [ ] 可以直接进入首发流程

---

## 9. 一句话原则

**如果封面、前 3 秒和最后一句金句不成立，这条片子就还没真正成立。**
