# Sample C Shotlist

## 项目
- 样片名称：遇见她以后
- 来源章节：第八章《遇见她》
- 目标时长：60-75 秒
- 主情绪：温柔、心动、命运转折
- 主平台：抖音 / 小红书 / B站

## 旁白主线
有些人出现以后，你才知道自己原来也值得被爱。她没有拯救我，她只是让我第一次想把日子过好。

## 节奏说明
- 0-3 秒：先给“我也值得被爱”的情绪锚点
- 3-25 秒：相识与相处的真实感
- 25-50 秒：理解、靠近、心动
- 50-70 秒：牵手、表白、一起生活的温柔收束

## 结尾金句备选
1. 原来真正的爱情，是让一个人慢慢变亮。
2. 她没有拯救我，她只是让我第一次想把日子过好。

## 封面建议
- 画面：两人对视，背景柔焦，光线温柔
- 文案：遇见她以后，我想把日子过好
