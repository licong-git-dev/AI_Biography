# Sample C 验收清单

## 1. 关键帧验收
- [ ] 第一眼相遇有命运感，但不过分偶像剧
- [ ] 回头一笑有好感，不假笑
- [ ] 毛坯房和做饭镜头真实，不摆拍
- [ ] 长谈镜头有被理解的感觉
- [ ] 对视定格可直接做主封面

## 2. 图生视频验收
- [ ] C-01 相遇镜头自然
- [ ] C-02 回头笑面部稳定
- [ ] C-05 餐馆长谈可信
- [ ] C-08 对视收束成立

## 3. 音频验收
- [ ] 旁白真诚，不油腻
- [ ] 张珂对白自然，有生活气
- [ ] 环境音增加真实感但不抢戏
- [ ] BGM 温柔但不腻

## 4. 字幕验收
- [ ] “毛坯房”“张珂”等词无误
- [ ] 单句长度适合手机端阅读
- [ ] 最后一句金句适合黑场/定格

## 5. 成片验收
- [ ] 前3秒立住“我也值得被爱”的情绪锚点
- [ ] 60-75 秒节奏顺畅
- [ ] 回头笑和结尾定格都能成为传播点

## 6. 发布包验收
- [ ] 主封面有温柔治愈感
- [ ] 标题、简介、标签齐全
- [ ] 可直接进入人工终审发布
