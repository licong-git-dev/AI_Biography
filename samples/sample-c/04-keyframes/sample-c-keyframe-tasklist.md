# Sample C 首批关键帧任务单

> 目标：先把 Sample C 的传播性镜头做出来，建立“被理解后的松弛感”视觉基调。

---

## Task KF-C-01 第一眼相遇

### 对应镜头
- `C-01`

### 目标
建立命运感的第一眼，不要做成偶像剧摆拍。

### 输入参考
- `Sample-C-Model-Prompt-Split.md` 中 C-01
- `Visual-Style-Bible.md`

### 输出要求
- 至少 3 张备选
- 必须有：人群、抬眼、注意到她的瞬间

### 验收要点
- 是否像“命运开始了”，但不油腻
- 是否具备传播性开头潜质

## Task KF-C-02 回头一笑

### 对应镜头
- `C-02`

### 目标
建立样片最重要的传播镜头之一：张珂回头一笑。

### 输出要求
- 至少 3 张备选
- 必须有：自然笑容、柔和光线、真实好感

### 验收要点
- 是不是自然，不是模板化美女图
- 能否直接当主封面候选

## Task KF-C-03 九锅一堂长谈
