# Sample C 旁白与对白成稿

## 样片
- 名称：遇见她以后
- 推荐旁白声线：青年李聪，温和、真诚、慢慢放松下来

## 主旁白成稿

有些人出现以后，你才知道自己原来也值得被爱。

最开始见她的时候，
我没觉得她会成为我的命运。
后来她来找我学主持，第一次走进我那间毛坯房。
我给她蒸了腊肠和汤包，笨拙得像在交一份人生答卷。

我们一起骑车，从汉口到武昌。
坐轮渡，吃小吃，聊那些谁都不轻易说出口的家庭往事。

她没有拯救我。
她只是让我第一次觉得，日子可以被认真地过好。

原来真正的爱情，
是让一个人慢慢变亮。

## 可选对白

## 录制建议
- 语速：中速偏慢
- 情绪：前半段带一点观察和试探，后半段明显变温柔
- 不要油腻，不要言情腔
