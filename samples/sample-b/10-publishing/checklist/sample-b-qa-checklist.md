# Sample B 验收清单

## 1. 关键帧验收
- [ ] 校门口镜头有孤立感
- [ ] 教室角落特写有紧绷感，不做夸张表情
- [ ] 夜里盯天花板镜头有压抑感
- [ ] 冲突后沉默镜头可信，不狗血
- [ ] 路灯背影有孤独感和收束感

## 2. 图生视频验收
- [ ] B-01 跟拍自然
- [ ] B-03 面部无明显漂移
- [ ] B-05 夜晚镜头安静稳定
- [ ] B-07 情绪真实不过火
- [ ] B-08 背影和路灯氛围成立

## 3. 音频验收
- [ ] 旁白是“压着说”，不是喊出来
- [ ] 妈妈/老师对白可信
- [ ] BGM 不过度煽情
- [ ] 环境音不抢台词

## 4. 字幕验收
- [ ] “叛逆”“完整的家庭”等关键词无误
- [ ] 字幕切分适合手机端
- [ ] 金句黑场清晰

## 5. 成片验收
- [ ] 前3秒立住“没人懂”的情绪锚点
- [ ] 整体时长 60-75 秒不拖沓
- [ ] 结尾金句有力量

## 6. 发布包验收
- [ ] 主封面能看出“少年 / 被误解”
- [ ] 标题 3 条、简介 2 条、标签齐全
- [ ] 可直接进入人工终审发布
