## 第一部分：出版前准备工作

### 1.1 作品版权登记（强烈建议）

版权登记是保护您作品的第一道防线。虽然著作权自作品完成之日起自动产生，但登记后可获得官方证书，在发生侵权纠纷时具有更强的法律效力。

#### 登记机构：中国版权保护中心

- **官方网站**：https://www.ccopyright.com.cn/
- **在线登记系统**：https://register.ccopyright.com.cn/
- **咨询电话**：010-68003887

#### 详细操作步骤

1. 访问 https://register.ccopyright.com.cn/，点击右上角【**注册**】按钮
2. 选择【**个人用户注册**】，填写手机号、邮箱、设置密码
3. 完成实名认证（需上传身份证正反面照片）
4. 登录后点击【**我要登记**】→【**作品著作权登记**】→【**文字作品**】
5. 填写作品信息：
   - 作品名称填：**李聪传**
   - 创作性质选：**原创**
   - 创作完成日期：如实填写
   - 首次发表日期：如未发表选"未发表"
6. 上传作品文件（PDF格式，建议添加水印"仅供版权登记使用"）
7. 在线支付登记费：**300元/件**（普通审核30个工作日）
8. 等待审核，通过后下载电子证书或申请纸质证书邮寄

#### 所需材料清单

| 材料名称 | 说明 |
|---------|------|
| 身份证 | 正反面扫描件，用于实名认证 |
| 作品样本 | 完整书稿PDF文件（建议加水印） |
| 创作说明书 | 简述创作过程、目的、独创性（500字左右） |
| 权利保证书 | 系统自动生成，在线签署即可 |

> **费用说明**：普通登记 **300元**（30个工作日）；加急登记 **600元**（10个工作日）

### 1.2 ISBN书号申请

ISBN（国际标准书号）是正规出版物的身份证。**个人无法直接申请ISBN，必须通过正规出版社。**

#### 申请方式对比

| 方式 | 优点 | 缺点 |
|-----|------|------|
| 传统出版社 | 免费获得ISBN，有编辑润色 | 门槛高，周期长（6-18个月） |
| 自费出版 | 门槛低，周期短（2-3个月） | 需支付书号费（约1-3万元） |
| 香港书号 | 费用低（2000-5000元） | 大陆销售受限，认可度较低 |

#### 自费出版书号代理机构（参考）

- **知网出书**：https://www.zhiwangchushu.com/
- **出书汇**：https://www.chushuhui.com/
- **出版社直接联系**：见后文推荐出版社列表

### 1.3 稿件整理要求

#### 格式规范

| 项目 | 要求 |
|-----|------|
| 文件格式 | Word文档（.docx）或 PDF |
| 字体字号 | 正文：宋体/仿宋 小四号（12pt）；标题：黑体 三号（16pt） |
| 行距 | 1.5倍行距或固定行距28磅 |
| 页边距 | 上下2.54cm，左右3.17cm（Word默认） |
| 页码 | 居中或右下角，正文从第1页开始 |

#### 书稿结构（建议）

1. 封面页（书名、作者）
2. 版权页（预留）
3. 作者简介（100-300字）
4. 序言/前言（可选）
5. 目录
6. 正文（第一章至第九章）
7. 后记/致谢（可选）

## 第二部分：自出版平台操作指南

自出版是最快捷的出版方式，无需ISBN也可发布电子书。以下为主流平台的详细操作步骤。

### 2.1 亚马逊 Kindle Direct Publishing (KDP)

全球最大的电子书自出版平台，可同时发布电子书和纸质书（POD按需印刷）。

#### 平台信息

- **网址**：https://kdp.amazon.com/
- **中国区**：https://kdp.amazon.cn/ （已关闭，需使用美国站或日本站）
- **推荐使用**：https://kdp.amazon.co.jp/ （日本站，支持中文书籍）

#### 详细操作步骤

1. 访问 **kdp.amazon.com**，点击【**Sign up**】注册亚马逊账号（如已有账号可直接登录）

2. 登录后进入 KDP 控制台，点击【**Create a New Title**】→【**Kindle eBook**】

3. **填写书籍信息**：
   - Language（语言）：选择 **Chinese (Simplified)**
   - Book Title（书名）：**李聪传**
   - Author（作者）：填写您的姓名
   - Description（描述）：300字以内的内容简介

4. **选择分类**：
   - 主分类：**Biographies & Memoirs** → **Personal Memoirs**
   - 可添加第二分类增加曝光

5. **上传书稿**：
   - 支持格式：.doc、.docx、.epub、.mobi
   - 建议使用 **.docx** 格式，系统会自动转换

6. **上传封面**：
   - 尺寸：**2560×1600 像素**（推荐）
   - 最小：1000×625 像素
   - 格式：JPG 或 TIFF

7. 使用【**Kindle Previewer**】预览效果，确认格式无误

8. **设置价格**：
   - $2.99-$9.99：可获得 **70% 版税**
   - 其他价格：**35% 版税**
   - 建议定价：**$4.99 或 ¥29.99**

9. 选择销售地区：建议勾选【**All territories**】全球发行

10. 点击【**Publish Your Kindle eBook**】提交审核
    - 审核周期：通常 **24-72小时**

#### 收款设置

在账户设置中完成税务信息和收款方式：

- **税务信息**：填写 **W-8BEN** 表格（非美国居民），可享受中美税收协定优惠
- **收款方式**：
  - 电汇到中国银行账户（需SWIFT代码）
  - 使用 **派安盈 Payoneer**（推荐）

---

### 2.2 豆瓣阅读

国内知名文学平台，适合文学类、散文类作品，读者群体文艺气质浓厚。

#### 平台信息

- **网址**：https://read.douban.com/
- **作者后台**：https://read.douban.com/author/

#### 详细操作步骤

1. 访问 **read.douban.com**，使用豆瓣账号登录（无账号需先注册）

2. 点击页面顶部【**写作**】→【**申请成为作者**】

3. 填写作者信息：
   - 笔名
   - 简介（突出写作特色）
   - 擅长领域
   - 上传头像

4. 提交作品试读章节（**至少3000字**）供编辑审核

5. 审核通过后，进入作者后台，点击【**创建新作品**】

6. 选择作品类型：【**原创作品**】→【**非虚构/传记**】

7. 填写作品信息：
   - 书名：李聪传
   - 简介：200-500字
   - 分类标签：传记、散文、非虚构

8. 上传书稿：
   - 支持在线编辑器直接粘贴
   - 或上传 **.docx** 文件

9. 上传封面：
   - 尺寸建议：**600×800 像素**以上
   - 格式：JPG/PNG

10. 设置定价：
    - 豆瓣阅读采用分成模式
    - 作者获得销售额的 **70%**

11. 提交审核，等待上架（通常 **3-7个工作日**）

### 2.3 掌阅 iReader

国内领先的数字阅读平台，用户基数大，适合大众读物。

#### 平台信息

- **官网**：https://www.zhangyue.com/
- **作者专区**：https://author.zhangyue.com/

#### 详细操作步骤

1. 访问 **author.zhangyue.com**，点击【**注册**】创建作者账号

2. 完成实名认证（需上传身份证）

3. 登录后点击【**创建作品**】→【**原创出版**】

4. 填写作品基本信息：
   - 书名：李聪传
   - 笔名：您的笔名
   - 分类：选择 **"现实/人物传记"**

5. 上传封面：
   - 尺寸要求：**600×800 像素**

6. 上传书稿：
   - 支持格式：.txt、.docx
   - 建议按章节分文件上传

7. 签署电子出版合同（在线点击同意）

8. 提交审核，通过后自动上架销售

### 2.4 微信读书

依托微信生态，用户量巨大，但个人入驻门槛较高。

#### 入驻方式

微信读书主要通过以下渠道入驻：

- **出版社/图书公司合作**：最主要渠道，需有正规ISBN
- **数字版权分销商**：如中文在线、阅文集团代理
- **个人作者申请**：通过公众号"微信读书作者服务"申请

#### 个人作者申请步骤

1. 微信搜索公众号 **"微信读书"**，关注后点击菜单【**作者服务**】

2. 填写作者入驻申请表（需提供已出版作品或代表作）

3. 等待平台审核回复（周期较长，约 **2-4周**）

4. 审核通过后，按指引上传作品

> **建议**：个人作者可先在其他平台发布，积累一定影响力后再申请微信读书。

### 2.5 当当云阅读

老牌图书电商平台的电子书板块，与纸质书销售联动。

#### 平台信息

- **官网**：http://e.dangdang.com/
- **出版合作**：需通过出版社或有ISBN的图书

#### 入驻说明

当当电子书主要面向出版机构开放，个人作者建议通过以下途径：

1. 先获得正规ISBN出版纸质书
2. 联系出版社同时制作电子书版本
3. 由出版社代为上架当当电子书

## 第三部分：传统出版社投稿

### 3.1 适合本书的出版社推荐

《李聪传》属于个人传记/非虚构类作品，以下出版社较为合适：

| 出版社 | 投稿邮箱/方式 | 特点 |
|-------|--------------|------|
| 作家出版社 | 官网在线投稿系统 | 纯文学、传记类首选 |
| 人民文学出版社 | rwcbs@rfrencb.com | 门槛高，品质好 |
| 长江文艺出版社 | 官网自助投稿 | 对新人友好 |
| 湖北人民出版社 | hbrmcbs@163.com | 鄂州本地，亲和力强 |
| 北京联合出版 | 与民营公司合作出版 | 出版速度快 |
| 团结出版社 | tjcbs@126.com | 自费出版门槛低 |

---

### 3.2 投稿材料准备

1. **投稿信/自荐信**（说明作品亮点、目标读者、作者简介）
2. **完整书稿**（Word格式）
3. **作品大纲/简介**（500-1000字）
4. **精选章节样章**（2-3章，便于编辑快速了解风格）
5. **作者简介**（100-300字，突出个人经历与写作特色）

---

### 3.3 出版合同注意事项

**签署出版合同前，务必注意以下条款：**

| 条款 | 注意事项 |
|-----|---------|
| 版权归属 | 确保"著作权归作者所有"，出版社仅获得出版权 |
| 授权范围 | 明确纸质书/电子书/有声书等各类权利的授权范围 |
| 授权期限 | 通常3-5年，**避免签"永久授权"** |
| 版税比例 | 纸质书通常6%-10%，电子书可达25%-50% |
| 首印数量 | 明确首次印刷数量，一般3000-5000册 |
| 结算周期 | 通常半年或一年结算一次版税 |
| 改编权 | 影视、游戏改编权**建议保留**或另行协商 |

## 第四部分：纸质书出版

### 4.1 POD按需印刷服务

POD（Print on Demand）是一种无需大量印刷库存的出版方式，读者下单后才印刷。

#### 国内POD平台

| 平台 | 网址 | 特点 |
|-----|------|------|
| 亚马逊KDP纸质书 | kdp.amazon.com | 全球发行，免费使用 |
| 京东印刷 | 印刷.jd.com | 国内配送快 |
| 当当POD | 需联系当当商家服务 | 与电商联动 |
| 虎彩印艺 | www.hucais.com | 专业POD服务 |

#### 亚马逊KDP纸质书操作步骤

1. 登录 **kdp.amazon.com**，点击【**Create**】→【**Paperback**】

2. 填写书籍信息（与电子书类似）

3. 选择开本尺寸：
   - 建议：**6"×9"**（接近国内32开）
   - 或 **5.5"×8.5"**

4. 选择纸张：
   - 白纸或奶白纸
   - 光面或哑光封面

5. 上传内文PDF（需按KDP模板制作，含出血位）

6. 上传封面PDF（使用 **KDP封面计算器** 生成模板）

7. 预览打样，检查无误后设置价格并发布

---

### 4.2 自费出版 vs 合作出版

| 项目 | 自费出版 | 合作出版 |
|-----|---------|---------|
| 费用 | 1-5万元（含书号费） | 0元（出版社承担） |
| 门槛 | 低，有钱即可 | 高，需编辑认可 |
| 发行渠道 | 有限，主要靠自己 | 出版社渠道，覆盖广 |
| 周期 | 2-4个月 | 6-18个月 |
| 版税 | 无版税，自销自得 | 有版税，通常6%-10% |
| 适合人群 | 急于出版、自用赠送 | 希望正规发行销售 |

## 第五部分：版权保护

### 5.1 如何防止侵权

1. **及时进行版权登记**，获取官方证书

2. 在作品中加入版权声明：
   > "本作品版权归作者李聪所有，未经授权禁止转载"

3. 发布前使用**时间戳服务**（如联合信任时间戳）固定创作时间

4. **定期搜索网络**，监控是否有未授权转载

5. 在各平台开启**原创保护功能**（如微信公众号原创声明）

---

### 5.2 维权渠道

发现侵权后，可通过以下渠道维权：

| 渠道 | 说明 |
|-----|------|
| 平台投诉 | 各平台均有侵权投诉入口，提交版权证明后可要求删除 |
| 12426版权监测 | 国家版权局"剑网行动"举报平台 |
| 版权调解 | 联系当地版权局进行行政调解 |
| 律师函 | 委托律师发送停止侵权律师函 |
| 诉讼 | 向法院起诉，要求停止侵权并赔偿损失 |

#### 重要联系方式

- **中国版权保护中心**：010-68003887
- **国家版权局**：www.ncac.gov.cn
- **12318全国文化市场举报网站**：www.12318.gov.cn

## 附录：常见问题解答

**Q1：没有ISBN可以出版吗？**

A：电子书可以不需要ISBN，在亚马逊KDP、豆瓣阅读等平台自出版即可。但正规纸质书必须有ISBN才能在书店销售。

---

**Q2：自费出版和正规出版有什么区别？**

A：自费出版需作者承担费用，出版社不负责发行；正规出版由出版社承担费用并负责发行，作者获得版税。两者的ISBN都是正规的。

---

**Q3：出版周期一般要多久？**

A：
- 电子书自出版：最快**当天上架**
- 传统出版：通常需要 **6-18个月**
- 自费出版：约 **2-4个月**

---

**Q4：如何提高被出版社选中的概率？**

A：
1. 投稿信要精练有力
2. 突出作品独特性和市场价值
3. 先在自媒体平台发布部分内容积累口碑
4. 参加文学比赛获奖增加背书

---

**Q5：版权登记和ISBN是一回事吗？**

A：不是。
- **版权登记**：证明作品著作权的官方登记
- **ISBN**：图书出版发行的国际标准书号

两者独立，建议都办理。
